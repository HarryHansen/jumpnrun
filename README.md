## What is this game about?

You control a character - a red square - moving through a parkour of platforms. At the same time, you have to collect some coins.
When you've collected all the coins, you can jump to the next level through a portal - a blue square.

## Rules

1. You start the level automatically. You can restart a level manually by pressing 'L'. But please keep in mind that the progress of this level will be lost.
2. You can move / jump using the arrow keys / space.
3. The little brown platforms will hold your weight permanently. You can use them to get your character to the portal.
4. After you have collected all the coins (the yellow dots), you can advance to the next level by jumping through the dark blue portal (refer to illustration 1 for details).
5. In the upper left corner you see how many coins you have already collected and how many you still need. In the upper right corner, you see which level you're at.
6. The dark brown platforms that appear from level 2 onwards will vanish after you touch them (and after a certain delay). You will be dropped, if you're still on them. But no worries, they respawn automatically after some time.
7. Sometimes, you will only be able to land on a platform by directly pressing an arrow key after the start.
8. In level 5, there you'll face button for the first time. Jump onto them and watch what happens.
9. You will sometimes see a few differently-colored coins. These are power-ups. You will get some special talents from them. These talents are just enabled for this level and will vanish afterwards. Check out table 1 below to get more information about this. If their time limit expires, you can't reactivate them. You'll have to restart the level (Press 'L' or reload the page).

| **Color**      | **Special talent**                                                                                                                      | **Time limit** |
| :------------- | :-------------------------------------------------------------------------------------------------------------------------------------- | :------------- |
| Orange         | You can jump higher                                                                                                                     | Infinite       |
| Purple         | Similar to 'Orange', but you'll be able to jump even higher. No worries if you get out of the playing field. You will drop down slowly. | Exists         |
| Salmon-colored | A circle will appear around you. Within this, all coins will be attracted to you (like a magnet).                                       | Exists         |

**Table 1:** Overview of the power-ups.

10. In some levels, there are spikes on the ground. If you touch them, you die and have to restart the level.
11. There are invisible platforms. You can't make them visible (besides with buttons). You'll notice them when you suddenly hang in mid-air.
12. Some platforms are colored differently. They might move (e.g. through a button or automatically).
13. In level 15, the playing field is suddenly divided in two parts. You can't jump through the barrier. You can use the portals (squares in different colors) instead. They will teleport you to the associated portal (sometimes marked with matching colors, sometimes not).
14. _Enjoy playing 🥳_

## How can I start playing now?

As this code uses ES Modules for JavaScript, you will have to use a server to run this properly.
The easiest way is using VS Code:

1. Download VS Code
2. Download the live server extension.
3. Open the folder of this project.
4. Run the live server.
5. _Start playing 🤩_
